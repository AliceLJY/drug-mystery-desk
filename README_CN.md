# 药研悬案局 Drug Mystery Desk

[English](./README.md)

由 Codex（OpenAI 的云端编码 agent）起头，后来交给 Minis——我 iPhone 上的 AI agent app，开源、跑在手机本地，模型可以挂 Codex 也可以挂 Claude——照我想要的推理探案方向，改造成现在的探案游戏。项目最早的 git 在 ChatGPT Apps 平台上；2026 年 10 月起，本仓就是唯一的代码来源，新案直接进这里。

一个以临床试验舞弊为题材的探案游戏。阅读证物，连接线索，击破证词——只有完整证据链才能结案。

**在线游玩：https://aliceljy.github.io/drug-mystery-desk/** ——手机和电脑浏览器都能直接打开，不用安装任何东西。

## 七宗悬案

| | 案件 | 题材 | 难度 |
|---|---|---|---|
| 01 | 消失的第七码 | 数据篡改 · 权限与时间线 | 入门，15–20 分钟 |
| 02 | 零下七码 | 样本调包 · 物证与流转链 | 进阶，20–25 分钟 |
| 03 | 盲区来客 | 身份替访 · 盲态与访视动线 | 困难，25–30 分钟 |
| 04 | 沉默的七小时 | 不良事件瞒报 · 报告时限与因果判定 | 困难，25–30 分钟 |
| 05 | 同一颗心跳 | 幽灵受试者 · 心电图与身份核验 | 困难，25–30 分钟 |
| 06 | 晚到七天的签名 | 知情同意造假 · 签名、日期与版本 | 困难，25–30 分钟 |
| 07 | 零点零七 | 主要终点偷换 · 统计计划与注册史 | 专家，30–35 分钟 |

所有案件均为虚构，不构成医学、投资或合规建议——游戏页脚自己也这么写。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

打开 `http://localhost:3000`。案件进度存在浏览器 local storage 里，不需要账号、也不需要数据库。

### 单文件版

`npm run build:standalone` 会把案件大厅和七宗案件打成一个自包含的 HTML 文件（`out/standalone/index.html`，约 840 KB，内联 React，不发任何网络请求）。GitHub Pages 上跑的就是这个文件：`.github/workflows/pages.yml` 在每次推送 `main` 时重新打包并部署。电脑上也可以直接双击它离线游玩。

## 项目由来

Codex 最初把它建成一个本地优先的"个人证据案卷"：追踪药物研究里悬而未决的问题——预测加置信度、来自 ClinicalTrials.gov 与 openFDA 的快照、一部带日期的判断修订史。我试了觉得不好玩，想把它做成推理探案。Minis 接手后先把不好玩的原因说清楚：产品循环不成立，一个披着侦探皮肤的仪表盘，等着数据库发生变化。于是照推理探案的方向，它保留了视觉语言和数据抓取层，把中间重做成现在就能推理结案的案件。第一案我玩到满分才要了第二案；第四案的题材（不良事件瞒报）是我从 Minis 给的三个方向里挑的；到了第五案，Minis 又给了三个方向，我全选了，于是第五到七案一起到来。那个早期形态里，`InvestigationDesk` 组件已经不再被页面引用；但 `evidence API` 路由（`/api/evidence`）按 Next.js 的文件约定仍会自动挂载，只是页面不再调用它——它还是一个无鉴权、只读代理 ClinicalTrials.gov / openFDA 的公开接口，部署到公网时可按需关闭。
