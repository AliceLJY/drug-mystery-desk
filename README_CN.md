# 药研悬案局 Drug Mystery Desk

[English](./README.md)

由 Minis——我在 ChatGPT 侧的 AI——在 ChatGPT Apps 平台上对话开发。本仓是那个项目的公开镜像。

一个以临床试验舞弊为题材的探案游戏。阅读证物，连接线索，击破证词——只有完整证据链才能结案。

## 三宗悬案

| | 案件 | 题材 | 难度 |
|---|---|---|---|
| 01 | 消失的第七码 | 数据篡改 · 权限与时间线 | 入门，15–20 分钟 |
| 02 | 零下七码 | 样本调包 · 物证与流转链 | 进阶，20–25 分钟 |
| 03 | 盲区来客 | 身份替访 · 盲态与访视动线 | 困难，25–30 分钟 |

所有案件均为虚构，不构成医学、投资或合规建议——游戏页脚自己也这么写。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

打开 `http://localhost:3000`。案件进度存在浏览器 local storage 里，不需要账号、也不需要数据库。

## 项目由来

这个项目最初是一个本地优先的"个人证据案卷"：追踪药物研究里悬而未决的问题——预测加置信度、来自 ClinicalTrials.gov 与 openFDA 的快照、一部带日期的判断修订史。那个早期形态（`InvestigationDesk` 组件与 evidence API 路由）仍留在仓内、只是没有挂到任何路由上；探案游戏从它长出来，接管了首页。
